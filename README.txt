# Crave — Mobile Food Delivery UI

This is a mobile-first HTML/CSS recreation inspired by the screens in your HCI PROJECT PDF.

## Files
- `index.html` — page structure and all app screens
- `style.css` — mobile UI styling and responsive layout
- `script.js` — screen navigation and demo interactions

## Run it on your Mac
1. Unzip the project folder.
2. Open `index.html` in Chrome, or open the folder in VS Code and use Live Server.
3. For a phone preview in Chrome, open DevTools → Toggle device toolbar.

## Included screens
Onboarding (3), sign up, login, forgot password, reset password, home, food details, cart, checkout, order success, orders, profile.

## Notes
- This is a front-end prototype for an HCI project. It does not connect to a real backend, user account, payment processor, or delivery service.
- Food illustrations use emoji and CSS gradients so the project works without downloading extra image files.
- Google Fonts are loaded online; system fallback fonts will be used if offline.
- Update the app name, sample user details, food names and colors to match your final Figma design and course requirements.
